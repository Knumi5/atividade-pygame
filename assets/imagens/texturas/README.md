# Texturas 3D das paredes

Coloque aqui as imagens das paredes com os nomes abaixo (recomendado tamanho quadrado, ex.: `256x256`, em `.png`, `.jpg` ou `.bmp`):

- `1.png`: parede comum do escritório
- `2.png`: terminal/computador com tarefa pendente
- `3.png`: terminal/computador com tarefa concluída

Enquanto algum arquivo ainda não existir nesta pasta, o `src/object_renderer.py` usa automaticamente uma textura padrão de escritório para o jogo não quebrar.
